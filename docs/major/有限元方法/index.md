工科的有限元分析课程，没啥大毛病。考虑的是工程上的问题，主要讲如何将一个真实的模型转换成一个有限元模型。其实这个课程的价值就在三次 Project ，课程内容又有工程问题又有理论分析。

老师全英文讲课，基本上只上两节课，偶尔会拿 Abaqus 实操，会停下来问有没有问题。最后一节课会发复习PPT，其实一份历年卷组合。教材有中文版的，但是PPT基本上能看的懂，不懂可以到网上查一下，没必要特意翻教材。也可以准备一个 Abaqus 的参考书做Project的时候会快一点。

传统有限元方法课程更多探讨的是如何采用有限元方法求解一个抽象的微分方程，找的资料大部分偏向于数院的有限元分析，课里面偶尔会讲到一两点，但这门课更像是一门 Abaqus 的介绍课程，~~毕竟某位老师问我：2.5 个学分的有限元能学到啥~~。

考试的话看一下历年卷大概清楚有什么样的题型，老师出卷**比较灵活**，因为是英文作答前面的概念题最好自己预测一下然后背一下，大题根据历年卷找对应例题和作业过一下。最后一道创新题实在没什么思路可以丢给ai，主要是训练一下建模的一些过程。
